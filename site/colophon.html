Colophon

How this page is made.

A static project page for a tool that makes no network calls. It loads no third-party assets, sets no cookies, and keeps its claims honest with a small checker.

The page

One HTML page, one stylesheet, one small script, and a self-hosted font. There is no framework, no build step and no runtime dependency. GitHub Pages deploys the site/ directory through .github/workflows/pages.yml.

scripts/check-site.py runs locally and in CI. It verifies that every local asset exists, that no runtime asset comes from another origin, that the page names the current <Version>, that the candidate status is present, and that false release claims are absent.

Type

Body and display type is Inter, a variable font, self-hosted as a latin subset. It is licensed under the SIL Open Font License 1.1; the license text is at assets/fonts/OFL.txt.

Terminal and label text uses the system monospace stack: Cascadia Mono, Consolas, DejaVu Sans Mono, then the platform default.

Design references

The design practice on this page refers to two public skill collections:

  • emilkowalski/skills — interface and motion guidance (MIT).
  • Motionsites-AI/claude-skill — the MotionSites web-builder skill instructions (MIT; its media collection is not used).

These are design references, not vendored code. No upstream media is hosted here, and the page implementation is original.

Truth

The page currently describes 0.4.0-rc.2, the release candidate at e738b52. There is no v0.4.0 tag, no GitHub Release and no public package feed. The four human gates are listed in the status section and in SDD/AGENDA.md.

When the project version changes, the checker fails until this page is updated. That includes the tag procedure, which names the site version line.

Privacy

No cookies, no analytics, no tracking pixels, no third-party scripts, no font CDN. The only network requests are for this origin's HTML, stylesheet, script, font and images. External links are ordinary links; following one leaves this page.
